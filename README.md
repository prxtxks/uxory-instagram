# uxory-instagram

Media for @uxory.co (usa/) and @uxory.in (india/). Public on purpose: schedulers (Metricool, Meta Business Suite) fetch media from these raw URLs. Nothing private lives here.

- `usa/`, `india/`: `posts/`, `reels/`, `carousels/`, `stories/`, `ads/`, plus `schedule.csv`
- File names: `<code>-<co|in>.png` (posts), `<code>-<slug>-reel.mp4` (reels). Codes match the review sheet and the design canvases (A1–D4 Batch 1, E1–H9 Batch 2).
- `brand/`: logos and the captions sheet.

Raw URL pattern: `https://raw.githubusercontent.com/prxtxks/uxory-instagram/main/india/posts/D3-in.png`
